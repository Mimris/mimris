# Ecosystem Navigation

## Product identity

- `mimris-site` is the public home for the Mimris ecosystem.
- This application is named **Mimris Modelling**.
- The header brand links to `https://mimris-site.vercel.app` in a new tab and is not an internal Home control.

## Navigation

- The internal `/` route remains the product start page and is labelled **Modelling start**.
- `/modelling` remains the primary modelling workspace.
- The header includes a useful cross-product link to **AI Workspace**, opening in a new tab with a ↗ indicator.
- External ecosystem and product links are visually distinct from internal application routes.
- The discontinued Kavca AS branding/link is not part of the application navigation.

## Responsive and accessibility requirements

- The brand link has an accessible label that identifies both Mimris and the ecosystem-home destination.
- Existing collapsed navigation behavior and product-route highlighting are preserved.
