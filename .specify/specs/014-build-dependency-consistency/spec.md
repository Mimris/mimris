# Feature Specification: Build Dependency Consistency

**Feature Branch**: `alpha`
**Created**: 2026-10-02
**Status**: Implemented and verified locally
**Input**: Resolve the build error caused by the missing `@vercel/analytics/next` module after integrating remote updates.

## User Scenarios & Testing

1. **Given** remote updates introduce a declared dependency, **When** the repository dependencies are installed using the frozen pnpm lockfile, **Then** the Analytics import resolves locally.
2. **Given** the project is installed, **When** the production build checks TypeScript, **Then** Selector does not import the unused and unsupported named `CLOSING` export from `ws`.
3. **Given** Next.js 15 generates production type declarations, **When** the build runs, **Then** `next-env.d.ts` references the generated production route declarations rather than development-only declarations.

## Requirements

- **FR-001**: Dependency installation MUST use the declared pnpm version and `pnpm install --frozen-lockfile` without introducing a competing npm lockfile.
- **FR-002**: Analytics MUST remain declared in `package.json` and `pnpm-lock.yaml`; resolving a stale installation MUST NOT remove its instrumentation.
- **FR-003**: Selector MUST NOT import unused server-side WebSocket symbols.
- **FR-004**: Next.js generated environment declarations MUST remain compatible with the repository's production build.
- **FR-005**: This fix MUST NOT alter persisted model or metamodel formats.

## Implementation

- Refreshed local dependencies with `corepack pnpm install --frozen-lockfile`. Analytics was already declared and locked; no dependency manifest change was necessary.
- Removed the unused `CLOSING` import from `src/components/utils/Selector.tsx`.
- Retained the production `next-env.d.ts` declarations generated by Next.js 15.5.19 during the successful build.

## Verification

- `require.resolve('@vercel/analytics/next')` resolves the installed module.
- `npm test`: all 60 tests pass.
- `npm run build`: passed TypeScript checking, compilation, and generation of all 33 static pages.
- Local dependency installation is not a Git artifact. Other checkouts must refresh dependencies after pulling updates and restart their development server.
