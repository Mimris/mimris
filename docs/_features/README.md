# Feature Documentation

Comprehensive documentation for specific features of the application.

## Feature Categories

### [Icon System](./icon-system/README.md)

Complete documentation for the icon system, including emoji icons, SVG icons, unicode characters, and the change icon modal interface.

## Adding New Features

When adding new features to the application:

1. Create a new subfolder under `_features/` with a lowercase hyphenated name
2. Add a README.md that explains the feature
3. Document implementation details, API usage, and user guide
4. Link to the feature from this main README.md

## Structure

```text
_features/
├── icon-system/          # Icon management system docs
│   ├── README.md
│   ├── emoji-icons.md
│   ├── svg-icons.md
│   └── ...
└── [future-features]/
    ├── README.md
    └── ...
```
