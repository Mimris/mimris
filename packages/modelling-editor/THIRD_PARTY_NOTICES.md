Those source notices are retained in the moved implementation. GoJS is supplied by the host as a peer dependency; the tested version is 3.1.10. The package does not bundle the GoJS library.

InspectorRow retains the Northwoods copyright notice from its original application module. Its runtime regex-parser dependency is distributed under its own package license.

SelectionInspector retains the Northwoods copyright notice from its original application module. colornames and printf are runtime dependencies distributed under their own package licenses.

Palette retains the Northwoods notice from its original application module. gojs-react is supplied by the host as a peer, alongside GoJS.
